# CANNABIS v1.5.1

## 今回の変更
- v1.5.1: HTML/CSS内に混入していた文字列の改行コードを修正。CSS・JS・manifest・Apple Touch Iconの読み込みURLにバージョンを付けてキャッシュ更新を促進。
- iPhoneホーム画面用Apple Touch Iconの参照を明示し、URLにバージョン識別子を付けて古いアイコンキャッシュを回避。PWA manifestのアイコン参照も更新。
- 社員マスター・設備台帳・設定の3アイコンのみ線画SVGに変更。他のメニューアイコンは維持。
- 案件進捗から「人員調整」を削除。進捗は見積承認・申請書類・日程調整・作業完了・売上処理。
- メニュー最下部にアプリバージョン CANNABIS v1.5.1 を表示。
- 管理者向け「社員マスター」を追加。社員の新規登録・編集・在籍/退職状態・ガントチャート表示順を管理。
- ガントチャートの社員行と予定登録の担当者候補を、社員マスターの在籍社員から生成。事務担当は「全社員」切替時に表示。
- 退職・非表示にした社員は通常のガント表示と予定登録候補から除外。既存の予定・勤怠履歴は削除しない。

## 保存・共有に関する注意
社員マスターは現時点では localStorage 保存です。社員マスターの登録内容は、このブラウザ/端末内でのみ有効で、他の社員端末とは共有されません。またGoogleログインを許可するFirestore employees/{uid} の登録とは別です。新入社員がログインするには、管理者によるFirestore側の社員登録も引き続き必要です。

案件・予定・勤怠などの業務データもFirestore同期は未実装です。Firebaseの有料プランへの変更は行っていません。

## 検証
JavaScript構文チェックとZIP整合性チェックを実施。iPhone実機での画面/操作確認は未実施です。
