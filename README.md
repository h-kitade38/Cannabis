# CANNABIS（カナビス）プロトタイプ v0.1

iPhone優先の冷凍設備業向け業務管理Webアプリの初期プロトタイプです。

## 起動方法
1. ZIPを展開します。
2. `index.html` をブラウザで開きます。
3. デモ社員とPINでログインします。

## デモログイン
- 管理者：1234
- 管理職：2222
- 事務担当：4444
- 現場担当：3333

## 実装済み
- ログイン画面（デモ用PIN）
- ホーム／ダッシュボード
- 案件一覧・検索・状態フィルター・新規登録・編集・削除・詳細
- 顧客一覧・検索・新規登録・編集・詳細
- スケジュール一覧・追加・編集・削除
- ロールに応じた簡易メニュー表示
- localStorageによるブラウザ内保存
- iPhone向けレスポンシブUI

## 注意
この版は提案・操作確認用です。データは利用したブラウザ内に保存され、他の端末とは共有されません。
PINはデモ用であり、セキュリティ機能ではありません。実運用には認証・サーバー側権限管理・データベース・バックアップが必要です。
レポート、申請書、見積、売掛、入金、勤怠、経営分析などは今後の開発対象です。
