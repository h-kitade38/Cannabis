# CANNABIS Prototype v0.2
このZIPは、CANNABISのホーム画面・MQ会計STRAC図・スケジュール表示の改訂イメージです。

## 起動
index.html をブラウザで開いてください。サーバー不要です。

## 今回の改訂
- ホームの順序：メインメニュー → 今日のスケジュール → 会社の状況
- 「最近の案件」はホームから除外
- MQ会計を添付画像のSTRAC表の構成に合わせた面積図で表示
- スケジュールの勤務区分：日中作業／閉店後作業／休日出勤
- 24時超の時刻を26:00などで入力・表示
- 予定は開始日のカレンダーに所属し、翌日に分割しない
- 社員別タイムライン表示（横スクロール対応）

## 注意
これは画面・操作確認用の独立したデモです。v0.1のログイン、案件・顧客データ、localStorage等とはまだ統合していません。MQ会計の数字もサンプルです。実データ共有や月次締め処理は未実装です。
