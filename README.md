# CANNABIS v1.6.0

## 今回の変更
- PC（画面幅900px以上）では左側固定ナビゲーションに切り替えるレスポンシブ表示を追加。
- ヘッダーに「テレビ表示」ボタンを追加。クリックすると同じURLの `?view=tv` で専用画面を開く。
- テレビ表示は当日1日分のガントチャート。日付・現在時刻を大きく表示し、現在時刻の線を表示。
- 時間軸は00:00〜30:00。翌日02:00は26:00として表示できる。
- テレビ画面は15秒ごとに画面内データを再読込し、時計は1秒ごとに更新。
- 既存のiPhone向け画面構成・メニュー・アイコン・保存形式は維持。

## 重要：自動更新の範囲
このv1.6.0の元データは `localStorage` 保存で、Firestoreへの予定データ同期（書き込み・リアルタイム購読）は実装されていません。したがってテレビ画面の自動再描画は同じブラウザ内の保存データを対象とし、別のPC/iPhoneで変更した予定がテレビへ自動反映されるものではありません。複数端末間での自動更新を実現するには、別途Firestore同期の実装が必要です。Firebaseの有料プラン変更は行っていません。

## テレビ表示の開き方
1. 通常URLでログインする。
2. PC画面右上の「テレビ表示」を押す。
3. 直接開く場合は同じURLの末尾に `?view=tv` を付ける（ログインは必要）。

## 既存のフォルダ構成
`cannabis_v12_src/` と `icons/` の名前・階層は変更していません。GitHubへアップロードする際も、ZIP内の `cannabis_v12_src` の中身を既存の公開フォルダ構成に合わせてアップロードしてください。
