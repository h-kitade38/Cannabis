# CANNABIS v1.3 修正版

v1.2をベースに、今回指定された修正を反映。

## 変更内容
- 案件詳細の進捗チェックに「見積承認」を追加。チェックを外すと材料へ戻し、後続の準備・作業・売上チェックを解除。
- 案件管理の会社盤・全案件一覧から詳細横の編集ボタンを削除。編集は案件詳細画面から行う。
- iPhoneの表示領域（dvh/svh）とセーフエリアを考慮し、ログイン画面・コンテンツ・下部ナビの高さと余白を調整。
- 月間スケジュールをカレンダーグリッドに戻し、月曜日始まり・日曜日終わりの日本式に変更。各日の予定名・担当者・場所・時間を表示。
- 勤怠画面のメールアドレス表示を削除。
- STRAC図内のG表記を「G 200」形式に統一（等号を削除）。
- STRAC画面に案件1件あたりのP・V・Mと案件数Qを追加。P=PQ/Q、V=VQ/Q、M=MQ/Q。P/V/Mは小数点1位表示、Qは整数。Q=0の場合P/V/Mは0.0。

## 保存・共有
従来どおりlocalStorage保存。Firestoreへの案件・スケジュール・勤怠同期は未実装。Firebase認証設定は変更していない。

## 検証
JavaScript構文チェックとZIP整合性チェックを実施。iPhone実機での表示・操作確認は未実施。
