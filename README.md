# CANNABIS v1.5

## 今回の変更
- STRAC画面にP・V・M・Qの関係図を追加。P/V/Mは月次PQ/VQ/MQを案件数Qで割った値（小数1桁）、Qは対象案件数。
- メニューおよびホームの機能タイルのアイコンを、統一した深緑・アイボリーのオリジナルアイコン画像に変更。
- ガントチャートの社員名列を横スクロール時に固定。
- 社員マスターの「役割」を「部署」に変更（役員／営業部／工事部／経理部）。
- 社員マスターに電話番号を追加。
- 通常ガント表示は工事部を表示し、「全社員」で全部署を表示。

## 注意
- 保存方式は従来どおりlocalStorageです。Firestoreへの業務データ同期は未実装です。
- Google認証・Firestoreの社員許可登録は従来どおりです。
- iPhone実機での表示・操作確認は未実施です。
